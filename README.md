# İDEONİX

Independent game and technology studio site for [ideonix.app](https://ideonix.app).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build in `dist`
- `npm run preview` — preview the production build

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`

Contact form delivery uses `VITE_CONTACT_ENDPOINT`. Until that variable is set, the form stays visual only and does not pretend to send.
